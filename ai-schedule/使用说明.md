# AI 日程（个人版）使用说明

> 版本 1.0.0 ｜ 个人单机使用，不需要账号
> 日程数据只存本机；只有「用 AI 识别」会把你输入的文字/图片发给硅基流动的云端模型（需填一个 API Key）。

---

## 零、先看这一条：程序不能放在中文路径里
Windows 上的 Electron 无法从**含中文字符的路径**启动，会直接崩溃、连窗口都不出现。

所以：

- **推荐用安装版**：它会装到 `C:\Program Files\AI-Schedule`（纯英文路径），
  并且自动在桌面建一个叫「**AI日程**」的快捷方式。**以后请从快捷方式启动**，不要直接去 Program Files 里翻 exe。
- **如果用压缩包**：请解压到纯英文目录，例如 `C:\AI-Schedule\`，再双击里面的 `AI-Schedule.exe`。
- **不要**把程序放在桌面、「下载」或任何路径里带中文的文件夹下（你的用户名是中文，所以
  `C:\Users\王一钧\Desktop\...` 这种路径一律不行）。

## 一、怎么打开

| 你拿到的文件 | 怎么用 |
| --- | --- |
| `AI-Schedule-Setup-1.0.0.exe` | 双击安装（会请求管理员权限），装到 `C:\Program Files\AI-Schedule`，桌面出现「AI日程」快捷方式 |
| `AI-Schedule-1.0.0-win.zip` | 解压到 `C:\AI-Schedule` 这类纯英文目录，双击 `AI-Schedule.exe` |

首次打开如果一条数据都没有，会看到"还没有任何日程，从这三步开始"，点「先建课程表」最快。

---

## 二、数据存在哪（重要）

```
C:\Users\<你的用户名>\Documents\AI日程\
├─ schedule.db          你的全部数据（就这一个文件）
└─ backups\             自动备份（最近 10 份）
```

- **换电脑或重装系统**：把整个 `AI日程` 文件夹复制走，放回同一位置即可。
- **想立刻看一眼**：设置页有「打开所在文件夹」按钮。
- 程序不联网、不上传任何内容，数据只在这台电脑上。

### 什么时候会自动备份

1. 每次正常退出程序
2. 每天第一次启动
3. 你在设置页点「立即备份」

超出 10 份会自动删最旧的。**从备份恢复前，程序会先给当前数据再做一份安全备份**，所以恢复错了也有退路。

## 三、四个视图怎么用

| 视图 | 适合做什么 |
| --- | --- |
| **周视图**（默认） | 一眼看本周。左边时间轴 00:00–24:00，今天那一列会高亮 |
| **日视图** | 看某一天。右侧面板列出当天的待办和**空闲时段**（比如"14:00–18:00 空闲 4 小时"） |
| **月视图** | 看整月。一格放不下会显示「+2 更多」，点它跳到那天 |
| **列表视图** | 按时间顺序看接下来 30 天 |

顶部 `←` `→` 翻页、`今天` 回到今天。快捷键：`←` `→` 翻页、`T` 回今天、`Ctrl+N` 新建、`Esc` 关闭弹窗。

## 四、记一条日程

**两种方式**：双击日历空白处（时间会自动填好你双击的位置），或点右上角「＋ 新建」。

新建窗口里「类型」决定这条是哪一种：

- **时间段** —— 有开始和结束时刻，比如「19:30–21:00 健身」
- **全天** —— 只有日期，比如「周六 回家」
- **待办** —— 只有截止时间，会出现在待办页并按紧急程度分组

想跨天？改「结束日期」那一栏。

---

## 五、浏览态和编辑态（避免误操作）

程序平时是**浏览态**：能看、能翻页、能新建、能勾"完成"，但**改不动已有日程**。

点右上角「**编辑**」才进入编辑态，这时才能拖动日程块改时间、拉下边缘改时长、删除日程。改完点「完成编辑」退回。

拖动或删除后，底部会出现提示条带「撤销」，5 秒内点它就能还原。

---

## 六、录课程表（一次录完，整学期自动排）

1. 左侧进「课程表」→ 点「新建学期」，填学期名、开学日期（第 1 周的周一）、总周数
2. 在课表格子里双击，填课名、老师、地点
3. 时间可以「按第几节」也可以「按具体时间」
4. 有单双周的课，在「单双周」里选；一门课不同周次不同老师就加两条

**作息时间表**：点「作息时间表」可改每节的起止时刻。改完保存，所有按节次排的课显示时间会一起变。

**临时调课**：在日历里点那节课 → 进编辑态 → 选「仅这一次改期」或「本次停课」。只影响那一次，其它周次不变；选错了点「撤销例外」。

## 七、用 AI 录课程表 / 记日程（云端模型）

> 这一版不再在本机跑模型，改成调用 **DeepSeek 官方接口**（`https://api.deepseek.com`）。
> 好处：不用下载 1.6 GB 模型、不吃显卡、不会卡界面；代价：要联网，且要填一个 API Key。

### 先填 API Key（只需一次）

1. 打开 <https://platform.deepseek.com> 注册/登录 → 「API keys」→ 新建一个 Key（形如 `sk-xxxx`）
2. 回到程序：左侧**设置** → **AI 助手（云端）** → 把 Key 粘到「API Key」框里，点一下别处（失焦即保存）
3. 同一栏里还能改「模型」和「接口地址」；默认是 `deepseek-chat` 与 `https://api.deepseek.com`；
   「开启深度思考」默认勾着——DeepSeek 官方接口的思考模型是 `deepseek-reasoner`，勾着时程序会自动换过去

> Key 保存在本机的数据文件（`文档\\AI日程\\schedule.db`）里，不会传到别处；请求由程序直接发往硅基流动。

### 课程表：一句话 / 截图

课程表页顶部有「**用 AI 添加课程**」，点「展开」：

1. **打一句话**：「每周一 1-2 节高等数学，A101，第 1-16 周；周三 3-4 节大学英语，单周」
2. **或者贴一张课程表截图**（`Ctrl+V` 粘贴 / 点「选择截图」/ 直接拖进来）
3. 点「**识别并填入**」

识别结果先进入「**待确认的课程**」列表——**这时还没进课程表**。可以逐条「编辑」/「删除」，都对了再点「**全部加入课程表**」。

> 课表里已经有的课不会重复添加：程序会把已有课程一并告诉模型，
> 万一模型还是重复给了，那一行会灰显并标「**已存在**」，确认时自动跳过（提示「跳过 N 门重复的」）。

### 日历：一句话 / 图

日历页顶部也有「**用 AI 记日程**」：

- 「明天下午 3 点和导师开会，实验室 302；周五前交实验报告」
- 「每周四下午两点组会，到 6 月底」——重复规则会带到待确认列表（标签上写着「每周 · 周四 · 到 2026-06-30」）
- 或贴一张活动通知截图

同样先进入「待确认的日程」，确认后才进日历。

### 右下角的 AI 状态窗

| 显示 | 含义 |
| --- | --- |
| `AI · 待命` | 还没调用过；点开能看到 Key 有没有填 |
| `AI · 连接中` | 正在等云端返回第一个字 |
| `AI · 生成中` | 模型正在写结果、正在改待确认列表 |
| `AI · 运行正常` | 上一次调用成功，随时可用 |
| `AI · 出错` / `AI · 已关闭` | 点开看原因（多半是 Key 或网络）／设置里关掉了 |

点这个标签会展开：当前模型、接口地址、Key 打码后的样子，正在跑时能直接「停止」。

### 小提示

- 免费额度有速率限制，短时间连续点可能返回 429，等几秒再试；
- 想确认接口支持哪些模型：设置 → AI 助手 → 「读取可用模型」，会列出 Key 能用的 id，点一下即可选用；
- 识别结果一定要过一眼再确认——模型的排版理解不保证 100% 正确。

- **课内 / 课外活动 / 个人生活** 用三种颜色区分，在日历里混着看，也可以进各自的分类页单独看。
- **待办页** 自动分成「逾期 / 今天 / 本周 / 以后」，已完成折叠在下面。
- 颜色可以在**设置**里改。

## 九、遇到问题怎么办

| 现象 | 处理 |
| --- | --- |
| 提示"数据目录不可用" | 检查 `文档\AI日程` 是否被删/改名；被改名就改回来，或从 `backups` 里恢复 |
| 提示"数据文件无法打开，可能已损坏" | 设置页 → 从最近一份备份恢复（恢复会自动重启程序） |
| 时间算得不对 | 检查该学期的开学日期是否填成了第 1 周的周一 |
| 课表里没有课 | 确认「今天」是否在该学期周次范围内，以及课程的周次范围/单双周设置 |
| AI 提示「还没配置 API Key」 | 设置 → AI 助手（云端）→ 填硅基流动的 Key（`sk-…`），点一下别处即保存 |
| AI 报 401 / invalid api key | Key 填错或已失效：重新生成一个再粘进来 |
| AI 报 429 / 请求太频繁 | 免费额度有速率限制，等几秒再点一次 |
| AI 报超时 | 检查网络能否访问 `api.siliconflow.cn`；公司网络需要放行 |
| AI 提示「当前模型不支持图片」 | `Qwen3.5-4B` 按文本处理：改用文字描述，或在设置里换支持视觉的模型 |
| AI 识别结果乱 | 截图尽量正、不要太花；先在「待确认」里逐条改，再点「全部加入」 |
| 双击程序没反应 / 秒退 | 这台机器的显卡子进程可能起不来。程序会自动记住并逐级降级（从 `--disable-gpu-sandbox` 起），**再启动一次**通常就好 |

## 十、这一版没有的东西

搜索与筛选、到点提醒、导出/导入数据文件、深色主题、云端同步、账号、手机端。这些都留到以后，数据格式已经预留了扩展空间。
