# AI 日程（个人版）

本地优先的桌面日程应用：课表、课外活动、个人生活三类日程统一管理，数据完全存在本机，不联网、不需要账号。

![electron](https://img.shields.io/badge/Electron-33-47848F) ![react](https://img.shields.io/badge/React-19-61DAFB) ![typescript](https://img.shields.io/badge/TypeScript-5.7-3178C6)

---

## 功能

**日历**

- 周 / 日 / 月 / 列表四种视图，默认周视图；顶部「全天」条显示全天与跨天日程
- 只有开始时间、只有截止时间的日程用**一道线**画在时间轴上（开始=实线，截止=虚线）
- 日历可标记「重要事项」，顶部显示倒计时（「还有 3 天 4 小时」，过期变红）
- 浏览态 / 编辑态分离：浏览态只能看与新建，编辑态才能拖动改时间、拉下边缘改时长、删除
- 拖动与删除可撤销；保存时给出重叠冲突提示（只提示不阻止）

**新建日程**

- 两种方式：**日期（单日）** 与 **时间段（可跨天）**
- 日期从弹窗里的小日历点选，不用手填
- 时间形态由填写内容自动推导：全天 / 只有开始 / 时间段 / 只有截止（待办）

**课程表**

- 学期管理（多学期并存，历史保留）、作息时间表可自定义
- 课程支持按节次或按具体时间录入、单双周、周次范围
- 整学期自动排进日历；单次课可以改期或停课，可撤销

**其他**

- 重复日程：每天 / 每周 / 每两周 / 每月 / 每年，含「仅这一次 / 这一次及以后 / 全部」三选一
- 待办按逾期 / 今天 / 本周 / 以后分组
- 自动备份：退出时与每日首次启动各一次，保留最近 10 份；恢复前会再备份当前数据
- 关闭窗口不退出，程序留在托盘（为后续提醒功能预留）

## 技术栈

| 层 | 选型 |
| --- | --- |
| 外壳 | Electron 33 |
| 界面 | React 19 + TypeScript 5.7 + Vite 5，样式手写 CSS |
| 存储 | SQLite（sql.js 的 WebAssembly 版本），单文件 `schedule.db` |
| 测试 | Node 内置 `node:test` + jsdom，624 项 |

## 目录结构

```
src/
├─ main/        主进程：窗口、托盘、中文菜单、数据库、备份
├─ renderer/    界面：React 组件与样式
├─ shared/      主进程与界面共用：日期、布局、重复规则、冲突、倒计时
└─ preload/     安全桥接
tests/          单元测试与界面测试
resources/      图标
```

## 开发

```bash
pnpm install          # 安装依赖
pnpm run dev          # 开发模式（Vite + Electron）
pnpm test             # 跑全部测试
pnpm run build        # 构建
pnpm run dist         # 打包成安装程序
```

## 数据存放位置

```
文档\AI日程\
├─ schedule.db      全部数据
└─ backups\         自动备份（最近 10 份）
```

换电脑时把整个文件夹拷走即可，没有任何云端同步。

## 已知限制

**程序必须放在纯英文路径下。** Windows 上的 Electron 无法从含中文的路径启动（进程会在
初始化阶段崩溃且没有任何提示），因此安装程序默认装到 `C:\Program Files\AI-Schedule`，
免安装版请解压到 `C:\AI-Schedule` 这类目录。
